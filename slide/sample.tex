\begin{frame}{Aggregate Computing: The paradigm}
    What is Aggregate Computing?
    \begin{block}{Aggregate Computing}
        Programming paradigm that treats large, interconnected systems of devices as a single, aggregate machine rather than focusing on individual components.
    \end{block}
    \vspace{0.3cm}
    {\Large\textbf{Key concepts}}
    \begin{itemize}
        \item \textbf{Collective behavior}: The focus is on programming the group, or "aggregate," as a whole.
        \item \textbf{Abstraction}: It provides a higher level of abstraction that hides the complexity of managing individual devices in a vast and dynamic network.
        \item \textbf{Logic}: The program logic is expressed as the manipulation of data structures that extend spatially and temporally (\textbf{Field Calculus}).
    \end{itemize}

\begin{frame}{Algorithm (Gossip-Gradient)}
    The algorithm is at the core of the system, allowing decentralized proximity messaging.
    \begin{block}{Description}
        \begin{itemize}
            \item \textbf{Objective}: Enable communication between nodes by finding the shortest path (\textbf{gradient}) to the message source.
            \item \textbf{Algorithm Family}: \textbf{Gossip-based} algorithm, which rely on local interactions between nodes to propagate information throughout the network. It uses a \textbf{Bellman-Ford-like} approach to compute the gradient.
            \item \textbf{Multiple Sources}: The algorithm can handle multiple message sources simultaneously, allowing nodes to receive messages from different origins.
            \item \textbf{Parameters}: Maximum propagation distance, expiration time (TTL).
        \end{itemize}
    \end{block}
\end{frame}
